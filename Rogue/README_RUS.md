# Rogue (Консольный roguelike)

Реализация классической игры Rogue (1980 года) на языке Java 21.

## Технологический стек

- Язык: Java 21
- Сборка: Gradle
- Консольный UI: Библиотека Lanterna
- Хранение данных: JSON

## Архитектура

Проект разделен на три независимых слоя:

- domain: Чистая бизнес-логика игры. Содержит сущности (Игрок, Противники, Предметы), логику боя, генерацию уровней и механику игрового процесса. Не имеет зависимостей от UI или базы данных.
- presentation: Презентационный слой. Отвечает за отрисовку графики в консоли и обработку ввода пользователя.
- datalayer: Слой доступа к данным. Отвечает за сохранение и загрузку игрового прогресса и статистики в формате JSON.

## Сборка и запуск

Проект собирается и запускается через Gradle Wrapper. Для старта игры из корня репозитория выполните команду:

```bash
./gradlew run
```
Для Windows:
```bash
gradlew.bat run
```


## Управление в игре

- WASD — перемещение персонажа.
- h — применить оружие из рюкзака.
- j — применить еду.
- k — применить эликсир.
- e — применить свиток.
- 0–9 — выбор конкретного предмета в списке при использовании.

## Особенности реализации

- Пошаговый рендеринг игрового поля (комнаты, коридоры, акторы, предметы) и интерфейса (статусная панель, инвентарь).
- Реализация «тумана войны» и системы прямой видимости с применением алгоритмов Ray Casting и алгоритма Брезенхэма.
- Процедурная генерация уровней, состоящих из 9 комнат, соединенных коридорами.
- Пошаговая боевая система с расчетом попадания (ловкость) и урона (сила).
- Система предметов (еда, эликсиры, свитки, оружие, сокровища) с изменением характеристик персонажа.
- Сохранение статистики прохождений и таблицы лидеров.
