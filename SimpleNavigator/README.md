# SimpleNavigator

Консольное приложение на Java для работы с графами: загрузка из файла, обходы, поиск кратчайших путей, минимальное остовное дерево, решение задачи коммивояжера, экспорт в dot-формат.

Функционал:
    1. Загрузка графа из файла.
    2. Обход в ширину (BFS) с выводом результата.
    3. Обход в глубину (DFS) с выводом результата.
    4. Поиск кратчайшего пути между двумя вершинами (алгоритм Дейкстры).
    5. Поиск кратчайших путей между всеми парами вершин (алгоритм Флойда‑Уоршелла).
    6. Поиск минимального остовного дерева (алгоритм Прима).
    7. Решение задачи коммивояжера с выводом результирующего маршрута и его длины.
    8. Экспорт графа в dot‑формат.

### Основные определения

**Граф** — это совокупность конечного множества вершин и множества ребер. Каждому ребру сопоставлены две точки из множества вершин графа, образующие граничные точки ребра.

**Виды графов по типу рёбер:**
* *Неориентированный* — граф, в котором перемещение между вершинами, соединёнными ребром, возможно в любом направлении.
* *Ориентированный* — граф, рёбрам которого присвоено направление. Направленные рёбра именуются дугами. Перемещение из одной вершины в другую возможно только по дугам соответствующего направления.
* *Взвешенный* - граф, рёбрам которого задан вес.

**Виды графов по достижимости узлов:**
* *Связный* — для любой вершины в графе есть хотя бы один путь до любой другой вершины в этом же графе.
* *Несвязный* — в графе отсутствует путь хотя бы между двумя его вершинами.

**Деревья**

***Дерево*** — это связный ациклический граф, в котором любые две вершины соединены лишь одним маршрутом.    
***Остовное дерево (остов)*** — это подграф данного графа, содержащий все его вершины и являющийся деревом.

* **Матрица смежности** — квадратная матрица, размерность которой равна числу вершин в графе, и в которой A[i][j] элемент матрицы содержит в себе информацию о ребре из вершины `i` в вершину `j`. Возможные значения, которые может принимать A[i][j]:
    + для невзвешенного неориентированного графа: 
        - 0 — ребра между вершинами нет
        - 1 — ребро между вершинами есть  
    + для взвешенного неориентированного графа: 
        - 0 — ребра между вершинами нет 
        - N — ребро между вершинами есть, и его вес равен N 
    + для невзвешенного ориентированного графа: 
        - 0 — дуги между вершинами нет
        - 1 — есть дуга (ориентированное ребро), которая направлена из вершины `i` в вершину `j`
    + для взвешенного ориентированного графа: 
        - 0 — дуги между вершинами нет
        - N — есть дуга (ориентированное ребро), которая направлена из вершины `i` в вершину `j`, и её вес равен N

В рамках данного проекта:
- Веса ребер являются натуральными числами.
- Могут быть петли.
- Рассматриваются только ненулевые связные графы.
- *Считаем, что номера вершин начинаются с 1.*

### Архитектура

**Класс Graph**

Хранит граф в виде матрицы смежности. Поддерживает взвешенные и невзвешенные, ориентированные и неориентированные графы.

Методы:

- loadGraphFromFile(String filename) — загрузка из файла.
- exportGraphToDot(String filename) — выгрузка в dot.

**Класс GraphAlgorithms**

Реализует алгоритмы на графах.

Методы:

- depthFirstSearch(Graph graph, int startVertex) — нерекурсивный поиск в глубину. Использует `самописный стек` - класс **Stack**.
- breadthFirstSearch(Graph graph, int startVertex) — поиск в ширину. Использует `самописную очередь` - класс **Queue**.
- getShortestPathBetweenVertices(Graph graph, int v1, int v2) — кратчайший путь между двумя вершинами (алгоритм Дейкстры).
- getShortestPathsBetweenAllVertices(Graph graph) — кратчайшие пути между всеми парами (алгоритм Флойда‑Уоршелла).
- getLeastSpanningTree(Graph graph) — минимальное остовное дерево (алгоритм Прима).
- solveTravelingSalesmanProblem(Graph graph) — задача коммивояжера (муравьиный алгоритм). Возвращает класс `TsmResult`:

    ```java
    class TsmResult {
        int[] vertices;    // массив с искомым маршрутом (с порядком обхода вершин).
        double distance;  // длина этого маршрута
    }
    ```

### Сборка и запуск

Проект собирается с помощью Makefile (требование учебной площадки).

Доступные цели:

- make all — полная сборка проекта.
- make clean — очистка артефактов сборки.
- make test — запуск тестов.
- make s21_graph — сборка модуля s21_graph.
- make s21_graph_algorithms — сборка модуля s21_graph_algorithms.
- make run — запускает консольное приложение в интерактивном режиме: после старта программа запрашивает у пользователя путь к файлу с графом и дальнейшие команды через консоль. Файлы с примерами графов размещены в папке `data`.
